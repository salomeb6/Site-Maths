Chapitre 5 bis : Équation produit nul

I. Équation produit nul

Définition : Une équation produit nul est une équation de la forme A × B = 0, où A et B sont des expressions.

Propriété : Si un produit de facteurs est nul, alors l'un au moins de ses facteurs est nul.

Si A × B = 0, alors A = 0 ou B = 0.

Remarque : On ne peut utiliser cette propriété que si on a un produit égal à 0.

  • (x + 3)(x − 5) = 0 et 3x(x − 2) = 0 sont des équations produit nul.
  • (x + 3)(x − 5) = 7 n'est pas une équation produit nul (le produit n'est pas égal à 0).
  • Si l'équation n'est pas un produit, on factorise d'abord : x² − 3x = 0 s'écrit x(x − 3) = 0. On ne divise jamais par x : on perdrait la solution 0.

Méthode : Pour résoudre une équation produit nul :

  1. On écrit : « Si un produit de facteurs est nul, alors l'un au moins de ses facteurs est nul. »
  2. On écrit : A = 0 ou B = 0, puis on résout les deux équations.
  3. On conclut : l'équation a deux solutions.

Exemple : Résoudre l'équation (2x + 6)(x − 4) = 0.

II. Équation de la forme x² = a avec a > 0

Propriété : Soit a un nombre strictement positif.

L'équation x² = a a deux solutions : √a et −√a.

Remarque : Il ne faut pas oublier la solution négative : 4² = 16 mais aussi (−4)² = 16.

Exemple : Résoudre les équations suivantes.

  1. x² = 16
  1. x² − 5 = 0

III. Lien avec les fonctions : calculer un antécédent

Rappel : si f(x) = y, alors y est l'image de x par f, et x est un antécédent de y par f.

Propriété : Chercher les antécédents d'un nombre b par une fonction f, c'est résoudre l'équation f(x) = b.

Méthode : Pour déterminer un antécédent de b par le calcul :

  1. On écrit l'équation f(x) = b en remplaçant f(x) par son expression.
  2. On résout l'équation.
  3. On conclut par une phrase : « Un antécédent de b par f est ... ».

Exemple :

  1. Soit f(x) = 3x − 5. Déterminer un antécédent de 7 par f.
  1. Soit g(x) = (x − 2)(x + 1). Déterminer les antécédents de 0 par g.

Remarque : Un nombre a toujours une seule image, mais il peut avoir aucun, un ou plusieurs antécédents (dans l'exemple 2, le nombre 0 en a deux). Sur la courbe, on lit des valeurs approchées des antécédents ; par le calcul, on obtient les valeurs exactes.
