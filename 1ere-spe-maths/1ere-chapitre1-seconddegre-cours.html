Chapitre 1 : Fonctions Polynômes du Second Degré

I. Fonction polynôme du second degré

Définition : On appelle fonction polynôme du second degré toute fonction 𝑓 définie sur ℝ par une expression de la forme :

𝑓(𝑥) = 𝑎𝑥² + 𝑏𝑥 + 𝑐

où les coefficients 𝑎, 𝑏 et 𝑐 sont des réels donnés avec 𝑎 ≠ 0.

Remarque : Cette forme est la forme développée de 𝑓.

Exemple : Ces fonctions sont-elles polynômes du 2nd degré ? Si oui, donner les valeurs de 𝑎, 𝑏 et 𝑐

𝑓(𝑥) = 3𝑥² - 7𝑥 + 3

𝑔(𝑥) = 12𝑥² + 3𝑥 - 1

ℎ(𝑥) = 4 - 2𝑥²

𝑘(𝑥) = (𝑥 - 4)(5 - 2𝑥)

𝑚(𝑥) = 5𝑥 - 3

𝑛(𝑥) = 5𝑥⁴ - 7𝑥² + 3𝑥 - 8

II. Forme canonique d'une fonction polynôme du second degré

Propriété : Toute fonction polynôme 𝑓 du second degré définie sur ℝ par 𝑓(𝑥) = 𝑎𝑥² + 𝑏𝑥 + 𝑐 peut s'écrire sous la forme :

𝑓(𝑥) = 𝑎(𝑥 - α)² + β,

Avec α = -𝑏2𝑎  et  β = -𝑏² - 4𝑎𝑐4𝑎

Cette écriture s'appelle la forme canonique de 𝑓.

Remarque : On remarque que 𝑓(α) = β.

IV. Équation du second degré

Pour résoudre l'équation 𝑓(𝑥) = 0, on calcule un nombre appelé discriminant. Son signe permet de savoir le nombre de solutions que possède cette équation, avant même de les calculer.

Définition : Une équation du second degré est une équation de la forme

𝑎𝑥² + 𝑏𝑥 + 𝑐 = 0

où 𝑎, 𝑏 et 𝑐 sont des réels avec 𝑎 ≠ 0.

Exemple : L'équation 3𝑥² - 6𝑥 - 2 = 0 est une équation du second degré.

Définition : On appelle discriminant de l'équation du second degré 𝑎𝑥² + 𝑏𝑥 + 𝑐 = 0 le nombre Δ

tel que  Δ = 𝑏² - 4𝑎𝑐

Propriété : Soit Δ le discriminant du trinôme 𝑎𝑥² + 𝑏𝑥 + 𝑐

Si Δ < 0Si Δ = 0Si Δ > 0
L'équation 𝑎𝑥² + 𝑏𝑥 + 𝑐 = 0 n'a pas de solution réelle. L'équation 𝑎𝑥² + 𝑏𝑥 + 𝑐 = 0 a une unique solution : L'équation 𝑎𝑥² + 𝑏𝑥 + 𝑐 = 0 a 2 solutions distinctes :
𝑆 = ∅ 𝑥0 = -𝑏2𝑎 𝑥1 = -𝑏 - √Δ2𝑎   𝑥2 = -𝑏 + √Δ2𝑎

Remarque : Les solutions de l'équation 𝑓(𝑥) = 0 sont appelées les racines de 𝑓. Graphiquement, ce sont les abscisses des points d'intersection de la parabole avec l'axe des abscisses : le nombre de solutions se lit donc sur la courbe (ici avec 𝑎 > 0).

V. Forme factorisée d'un polynôme du second degré

Propriété : Soit 𝑓(𝑥) = 𝑎𝑥² + 𝑏𝑥 + 𝑐 de discriminant Δ.

  • Si Δ > 0, alors 𝑓(𝑥) = 𝑎(𝑥 - 𝑥1)(𝑥 - 𝑥2)
  • Si Δ = 0, alors 𝑓(𝑥) = 𝑎(𝑥 - 𝑥0)²
  • Si Δ < 0, 𝑓 n'admet aucune racine : elle ne peut pas être factorisée (sur ℝ).

Exemple : Factoriser, si possible, 𝑓(𝑥) = 2𝑥² - 5𝑥 + 3

VI. Somme et produit des racines

Lorsqu'un polynôme du second degré admet deux racines, leur somme et leur produit s'expriment directement à l'aide des coefficients 𝑎, 𝑏 et 𝑐, sans calculer les racines.

Propriété : Soit 𝑓(𝑥) = 𝑎𝑥² + 𝑏𝑥 + 𝑐 de discriminant Δ > 0, de racines 𝑥1 et 𝑥2. Alors :

𝑆 = 𝑥1 + 𝑥2 = -𝑏𝑎 et 𝑃 = 𝑥1 × 𝑥2 = 𝑐𝑎

Remarque : Si l'on connaît une racine (par exemple une racine « évidente » trouvée en testant 0, 1, -1, 2...), le produit ou la somme permet d'obtenir l'autre racine sans calculer Δ.

Exemple : Vérifier que 1 est racine de 𝑓(𝑥) = 2𝑥² - 5𝑥 + 3, puis en déduire l'autre racine sans calculer Δ.
